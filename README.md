# ⏱️ Stopwatch

A simple and responsive **Stopwatch Web Application** built using **HTML, CSS, and JavaScript**. The application allows users to start, pause, reset, and track elapsed time through an easy-to-use interface.

## 🚀 Live Demo

🔗 [View Live Stopwatch](https://stopwatch-nlws.onrender.com)




## ✨ Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the timer
- ⏱️ Real-time time tracking
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
